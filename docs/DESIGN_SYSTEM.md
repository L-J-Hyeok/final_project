# 기기로움 통합 디자인 및 인터랙션 시스템 (Design System)

> Apple의 제품 중심 미학, Samsung의 직관적 카테고리 탐색, nofee.team의 간결한 웹앱 사용성을 결합한 제조사 중립적 IT 플랫폼 표준 규칙. 향후 **PC-FIT (조립 PC 추천·호환성)** 화면까지 동일하게 확장 적용한다.

---

## 1. 핵심 시각 원칙
- **컬러 체계:** 화이트(`#FFFFFF`) · 라이트 그레이(`#F5F5F7`) · 블랙(`#111111`) · 뉴트럴 그레이(`#52525B`, `#71717A`, `#E5E5E7`).
- **시맨틱 보존:** 경고·개발용 참고 가격(`#92400E` / `#FFFBEB`), 오류(`#B42318` / `#FEF2F2`), 검증/유지(`#176B50` / `#ECFDF5`)는 의미 인지력을 위해 고유 색상을 반드시 유지한다.
- **버튼 계층:** 주 CTA는 블랙 필(`border-radius: 9999px`, `#111111` bg), 보조 CTA는 1px 아웃라인 필 또는 밑줄 텍스트 링크로 통일한다.
- **여백과 밀도:** 과도한 박스 그림자(`box-shadow`)와 중복 테두리를 지양하고, 넓은 패딩과 `1px solid #E5E5E7` 헤어라인으로 영역을 구분한다.

---

## 2. 공통 인터랙션 기법 (선택적 적용 기준)
모든 기법을 남용하지 않고 실제 의사결정과 탐색 효율을 높이는 기법만 화면 성격에 맞게 배치한다.

| 기법 | 적용 화면 | 사용 목적 |
| :--- | :--- | :--- |
| **Hero Visual Carousel** | 메인(`/`) | 통합 플랫폼·AI 추천·스펙 비교·PC-FIT(예정) 핵심 가치 전달 (수동 조작 시 자동전환 정지) |
| **Sticky Comparison Header** | `/compare` | 스크롤 시에도 현재 비교 중인 제품명과 교체/추가 상태를 상단에 고정 유지 |
| **Key Highlights + Accordion** | `/compare` | 기본 화면에서는 핵심 4~6개 지표만 시각적으로 노출하고, 긴 전체 스펙표는 아코디언으로 점진적 공개 |
| **Skeleton Loading** | `/compare`, `/recommend` | 데이터 조회 중 레이아웃 흔들림(CLS) 방지 및 안정적인 대기 상태 전달 |
| **Step-by-Step Wizard** | `/recommend` | 설문지 형태의 긴 폼을 `01 예산 → 02 사용 목적 → 03 선호·확인` 단계형 구매 가이드로 전환 (입력값 보존) |
| **Micro-interaction & State Transition** | 전 화면 | 선택 카드 하이라이트, 버튼/탭 전환 시 짧은 `160~240ms` CSS 전환 |
| **Product Gallery / Card** | `/recommend` 결과, (후속 `/devices`) | 제품 외형과 핵심 사양을 시각적 주인공으로 배치 |

---

## 3. 접근성 및 안전성 기준
- **`prefers-reduced-motion` 준수:** 모션 감소 설정 시 모든 전환(`transition`)·스켈레톤 애니메이션·자동 슬라이드 전환을 즉시 비활성화한다.
- **상태 무결성:** 단계 전환이나 애니메이션 도중 사용자가 입력·선택한 조건값이 절대 초기화되지 않도록 상태를 유지한다.
- **키보드 및 포커스:** 모든 인터랙티브 요소는 `Tab` 탐색과 `Enter`/`Space` 조작이 가능하며 `2px solid #111111` 고대비 포커스 링을 제공한다.
- **데이터 정직성:** API에 없는 사양·임의 제품 실물 사진·가짜 가격을 생성하지 않으며, 이미지 누락 시 카테고리별 일관된 SVG 플레이스홀더를 유지한다.

---

## 4. 향후 확장 가이드 (PC-FIT 포함)
- `/devices`, `/profile`, `/history`, `/upgrade` 및 향후 통합될 `/pc` (조립 PC 견적 · 호환성 검사) 화면도 동일한 CSS 변수(`--surface-gray`, `--ink-black`, `--border-hairline`), `.skeleton-block`, `.accordion-panel`, `.step-wizard-bar` 공통 패턴을 재사용해 일관된 플랫폼 경험을 제공한다.
