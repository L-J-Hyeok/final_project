# 프로젝트 개요

## 목적과 현재 단계

가칭: **AI 기반 개인 맞춤형 IT 기기 및 조립 PC 추천 플랫폼**.

생활스타일·소비 성향·브랜드 선호·기존 기기를 함께 고려하는 장기적인 IT 구매 컨설팅 서비스다. 자체 MySQL의 검증 가능한 제품 데이터를 바탕으로 AI가 개인 적합성과 추천 순위를 판단한다. 단순 검색과 달리 기존 기기 유지·구매 보류도 제안한다.

스마트폰 백엔드와 프론트엔드 일부가 구현된 기존 프로젝트다. 개별 단계의 이전 검증 보고와 스마트폰 MVP 전체 통합 완료는 구분한다. 현재 우선 작업은 제품 데이터 확장·가격 검증 및 미완성 사용자 흐름의 연결이며, 다른 IT기기는 아직 구현 대상으로 확대하지 않는다. 실제 진행 상태는 [CURRENT_STATUS.md](CURRENT_STATUS.md)에서 관리한다.

## 사용자 흐름과 핵심 기능

1. 회원가입·로그인.
2. 최초 성향·생활스타일 자연어 입력.
3. AI가 소비 성향·브랜드 선호·사용 목적·중요 성능을 구조화한 프로필 초안 생성.
4. 사용자가 분석 결과를 확인·수정·확정.
5. 현재 기기를 카테고리·제조사·모델·옵션으로 직접 검색·등록.
6. 프로필과 보유 기기를 MySQL에 저장하고, 보유 스마트폰의 국내 공식 출시일을 즉시 확인(기존 회원도 재방문·로그인·기기 변경 시 현재 날짜 기준으로 재평가).
7. 국내 공식 출시일 기준 **3년 이상 경과한 스마트폰** 보유 시 업그레이드 제안 알림 표시(‘업그레이드 추천 받기’, ‘나중에 보기(30일 유예)’, ‘이 기기에서는 다시 표시하지 않기’). 출시 3년 미만 사용자는 팝업 없이 일반 스마트폰 추천을 언제든 이용 가능.
8. 신규 구매·교체 상담과 이번 구매 조건(및 기존 기기 만족 요소·불만 요소·교체 의향) 입력.
9. 기존 프로필·보유 기기·이번 조건 통합, 필요 시 추가 질문.
10. Express가 검증된 조건으로 MySQL 후보 조회 및 보유 기기와의 객관적 사양 비교 생성.
11. AI가 내부 DB 후보 비교·개인 적합성 판단·순위·이유 또는 **현 기기 유지(`status='keep'`)** 판단 생성(실시간 웹 검색 및 Google Search Grounding 금지).
12. Express가 후보 ID·예산·필수 조건·데이터 일치 및 현 기기 유지 조건 충족 여부를 재검증.
13. Vue에서 이유·장단점·보유 기기 대비 객관적 변화와 불확실성·가격 출처와 시점·가성비 대안 또는 현 기기 유지 근거 표시.
14. 추천 이력 저장, 프로필·보유 기기 수정·삭제 및 지속 관리.

자연어와 직접 선택 UI는 병행한다. 예: “대학생이고 유튜브·코딩 위주, 게임은 거의 안 하며 가성비 중시, 삼성 선호지만 대안 허용”을 구조화하되 언급하지 않은 예산·성능 수치는 추정하지 않는다. 사용자가 직접 확정한 값은 AI가 묵시적으로 덮어쓰지 않는다.

성향은 공통 성향, 제품군별 선호도, 이번 구매 조건으로 분리한다. 이번 예산을 영구 성향으로 저장하려면 사용자의 별도 확인이 필요하다.

## 보유 기기 기반 개인화 업그레이드 추천 및 다중 기기 확장 원칙

- **출시 경과 기간과 개인 실사용 기간의 구분**: 업그레이드 안내 기준은 개인 구매일·실사용 기간이 아닌 **모델의 국내 공식 출시일(`released_on_kr`) 기준 3년 경과 여부**다. 출시일이 없거나 세부 모델을 특정할 수 없으면 추측하지 않고 `확인 필요(needs_verification)`로 처리한다.
- **신규 회원 및 기존 회원 재평가**: 신규 회원이 스마트폰을 등록할 때 즉시 판정하며, 기존 회원도 고정 플래그에 의존하지 않고 서비스 재방문(`GET /api/upgrade-offer`) 및 기기 수정·삭제 시 현재 KST 날짜와 출시일을 다시 비교한다.
- **현 기기 유지(`keep`)도 정상 추천 결과**: 무조건적인 신제품 구매 유도를 금지한다. 현재 보유 스마트폰이 필수 조건을 충족하고 교체 체감 이득이 낮거나 현 기기 만족도가 높으면 **현 기기 유지(`status='keep'`)**를 1순위 결론으로 제안한다.
- **다중 IT기기 확장 구조**: 스마트폰(출시 3년, 활성)을 시작으로 향후 노트북(출시 4년, 예정), 태블릿(출시 4년, 예정), 스마트워치(출시 3년, 예정), 데스크톱/조립 PC(단순 출시일이 아닌 성능·호환성·부품 상태 중심, PC-FIT 연동 예정)로 동일한 업그레이드 정책 레지스트리 구조를 확장한다.

## 스마트폰 MVP 범위 — 확정

- 삼성전자·애플, 국내 자급제 신제품 중심.
- 추천 실행 시점 기준 국내 출시 3년 이내. 고정 연도 목록 사용 금지.
- Galaxy S·Z·A·FE, iPhone 일반·Plus·Pro·Pro Max·e·Air 등은 분류 후보다. 해당 기간 실제 국내 출시가 검증된 모델만 포함하며, 이름의 나열만으로 출시·판매 사실을 가정하지 않는다.
- 국내 모델번호·국내 출시일·저장 용량·세부 옵션 구분.
- 보유 기기 등록은 제조사·출시 시기 제한 없음. 미등록 모델은 사용자 입력과 미검증 표시를 지원하는 방향으로 설계.
- 상세 날짜 경계는 [아키텍처](ARCHITECTURE.md)의 제안과 D-006을 확정한 후 구현.

## UI/UX 방향

화이트·차콜·딥블루 중심의 전문적인 IT 서비스. 가독성·명확한 정보 계층·여백·직관적인 탐색과 비교를 우선한다. 주요 화면은 로그인, 단계별 온보딩, 프로필 편집, 보유 기기 검색·등록, 자연어 상담, 추가 질문, 추천 결과·비교, 추천 이력이다.

로딩·빈 상태·오류·재시도·저장 여부를 설계한다. 결과에는 옵션, 가격 출처·확인 시점, 기존 기기 대비 변화와 불확실성을 표시한다. 키보드 탐색·레이블·포커스·대비·동작 감소 설정, 데스크톱·모바일 반응형을 고려한다.

사용자 지정 참고: [Nofee](https://nofee.team/). 이번에는 접속하지 않았으며 실제 화면 분석 결과가 아니다. 탐색·비교 경험의 참고 후보로만 기록하고 디자인·문구·자산은 복제하지 않는다. Taste 제한은 [공통 규칙](DEVELOPMENT_RULES.md)을 따른다.

## 핵심 기능: 사용자가 직접 선택하는 제품 스펙 비교

AI 개인화 추천·보유 기기 업그레이드 제안과 함께 제품 스펙 비교를 서비스의 핵심 기능으로 제공한다. 사용자는 원하는 제품을 직접 선택해 객관적 사양을 나란히 비교한다. 추천 요청 없이 독립적으로 사용할 수 있으며 일반 비교는 Gemini를 호출하지 않는다. 제품명·사양·가격은 내부 MySQL의 검증된 데이터만 사용한다.

스마트폰 MVP는 2~3개 제품의 화면 크기·주사율·RAM·저장 용량·배터리 용량·무게·유효 가격을 비교한다. 다른 값은 차이만 강조하고 누락/미검증 사양은 ‘정보 없음’으로 표시한다. 수치가 크다고 우수하다고 판단하지 않는다. 현재 보유 스마트폰과 후보 제품 비교는 후속 연결 대상이다.

공통 비교 UI와 기기별 항목 정의를 분리한다. 노트북(CPU/GPU/RAM/저장/화면/무게/배터리), 태블릿(화면/칩셋/펜 지원/배터리/무게), 스마트워치(화면/센서/배터리/스마트폰 호환성), 조립 PC(부품 성능/호환성/총견적)는 향후 계획이다. 현재 실제 개발 대상은 스마트폰이며 PC-FIT을 이번에 통합하지 않는다. 구현 진척은 CURRENT_STATUS를 따른다.


## 향후 관리자·제품 데이터 운영 및 UI 개선 — 확정 계획, 미구현

- 관리자 전용 페이지에서 제품 모델·옵션·사양·가격·출처·검증 상태·수집 내역을 관리한다. 관리자 권한은 Express에서 매 요청 검증한다.
- TechSpecs API는 사용하지 않는다(D-028, D-008 대체). 제조사 공식 자료와 다나와 등은 사이트별 이용약관·robots.txt·자료 재사용 권한을 확인한 허용 범위에서만 활용한다. robots.txt 허용만으로 재사용 권한을 확보한 것으로 간주하지 않는다. 접근 제한 우회, 무단 대량 수집, 이미지·설명 복제는 하지 않는다.
- 출처 URL·확인 일시·국내 모델번호·검증 상태를 관리하고 정규화·검증·관리자 승인된 정보만 추천에 사용한다. 이번에 자료 이용 권한을 확인한 것은 아니며 수집·관리자 기능은 미구현이다.
- 프론트 1단계는 초기 UI다. Vue/Vuetify와 공통 컴포넌트를 재사용하면서 시각적 완성도를 별도 단계에서 개선한다. 이번 전면 재설계 없음.
- 스마트폰 MVP 우선 완성 후 노트북·태블릿·스마트워치·PC-FIT으로 확장한다.
