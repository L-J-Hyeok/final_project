# 스마트폰 검증 단계 분리 및 기존 자료 재분류

검토 시각: 2026-11-11 04:50:14 KST. Codex, 문서 전용·오프라인 검토. 추가 검색/DB 연결/마이그레이션/적재 없음. 기존 조사 JSON 두 개와 SMARTPHONE_PRIORITY_VERIFICATION.md, SMARTPHONE_DB_EXTENSION_DESIGN.md 및 실제 DDL/API 코드를 대조했다. **원자료의 verified/production_approved를 변경하지 않았고, 아래는 사실 검증 및 등록 후보 분류이지 실제 적재 승인이나 완료가 아니다.**

## 1. 이전 기준의 문제와 대체 기준

이전 ‘0개’는 모든 색상 SKU·전체 사양·권리/검수·운영 적재 준비를 합친 수치였다. 사실 검증 수치로 사용하면 지나치게 엄격하고 오해를 유발한다. 모델 전체 변형이 확인돼야 한 변형을 인정하는 조건과 출고가/현재가 확보를 사양 검증 조건으로 삼는 해석을 폐기한다. 기존 운영 승인/자료 이용 정책은 사실 검증과 별도 관리한다.

| 단계 | 완료 기준 | 누락 허용/분리 |
|---|---|---|
| A 모델 | 제조사·제품명·국내 모델번호·국내 일반 판매일, OS 계열, 근거가 연결된 핵심 사양과 공식 URL | 이 검토의 핵심 사양은 칩셋과 주 화면 정보. 화면은 크기 또는 해상도. OS 버전·카메라 전체·밝기·충전·RAM·mAh 전체 완비는 요구하지 않음. 미확인 값은 null |
| B 변형 | 해당 국내 모델의 실제 용량·RAM(미공개 null 허용)·색상 구성 판매 근거 | 제조사 전체 SKU 코드가 반드시 필요한 것은 아님. 명시적인 구성/전용 색상 근거도 인정. 모델 전체 색상 수집은 불필요. 색상 목록과 용량 목록의 단순 곱집합은 금지 |
| C1 공식 출고가 | 출시 당시 원화 금액·출처·적용 용량/RAM/색상 범위 | 누락 null 허용. B 완료를 취소하지 않음. 용량 수준 금액과 색상 특정 변형 연결 완료를 별도 집계 |
| C2 현재 판매가 | 정확한 변형, 판매처/구매 URL, 관측/만료, 배송비/재고/신품/자급제/무조건 구매 근거 | A/B/C1과 독립. 없으면 가격 관측 행을 만들지 않음. 출고가로 대체하지 않음 |

OS 계열(android/ios)은 출시 당시 버전과 다르다. iPhone Air는 기존 검증 문서의 현행 iOS27 기록으로 **ios 계열만** 인정하고 출시 버전은 null로 둔다. 나머지 Apple/Fold의 OS가 현실에서 무엇일지 추측하거나, 과거 미검증 baseline의 값을 브랜드만 보고 승격하지 않는다. 해당 자료의 OS 계열 누락은 확인 항목이며 모델이 존재하지 않는다는 판정이 아니다. 비공개 Apple RAM/mAh는 검증 보류 사유가 아니다.

## 2. 재집계 — 분모와 의미

전체 52는 DB기존11+미적재41. 위 신규10은 우선9+S25 Edge1이다. 기존16모델/29변형은 별도 보존 집합이며 이 수치에 신규로 더해 세거나 재검증 완료로 표시하지 않는다. 전체 조사 범위 밖 기존2023년5모델도 그대로 보존한다. 신규41의 A 분류는 완료10/추가 확인31(그중 식별/출시 보류8). **모델 행만 표현 가능한 신규10개와, 사용자 선택에 바로 사용할 변형을 갖춘2모델을 구분한다.**

출고가35/70은 원본의 용량/RAM 구성 금액 근거 수이지 검증된 색상 SKU 수가 아니다. S24 FE 가격의 기존256GB 연결은 원본 충돌 기록에 따라 보류하며 70개 전부를 정확한 옵션 가격으로 승인하지 않는다. 공식 출고가가 null인 14개 우선 구성(전체29개)은 가격 누락만으로 B 보류하지 않는다. 현 자료에서는 독립적인 색상 대응 근거 등이 남아 있어 2개 외 B 완료로 집계하지 않았다.

근거는 기존 자료의 [S25 Ultra 공식 출시자료](https://www.samsung.com/sec/business/insights/news/news_250203_06/)와 [S26+ 구성](https://www.samsung.com/sec/smartphones/galaxy-s26/buy/?modelCode=SM-S947NZKAKOO) 및 JSON sources의 s25price/s26이다. 이번에 URL에 재접속하지 않았다.

현행 smartphones/variants는 가격 행 없이 등록 가능하며 RAM null도 허용한다. 두 변형은 서로 다른 모델이고 각 모델당 한 변형이므로 현행 UNIQUE(model,storage,color)에 충돌하지 않는다. 현재 두 신규 모델은 이전 DB 대조 보고 기준 미적재이며 실행 직전 중복 대조는 별도로 필요하다. 현행에는 출고가 컬럼이 없으므로 사양 등록 시 C1은 외부 문서에 남기고 price_observations에 넣지 않는다. 확장 후 launch_price_krw/metadata로 보존할 수 있다. **확장은 증거 부족을 해결하지 않으므로 후보 수를 자동 증가시키지 않는다.**

출고가 누락 변형도 A+B가 충족되면 현행은 가격 행 없이, 확장 후에는 launch_price_krw=null/metadata에 unknown 사유로 안전하게 표현할 수 있다. 가격을 0으로 채우거나 출고가 확보 전까지 모델 전체를 대기시키지 않는다. 현재 color=unspecified 기본값은 SQL상 허용되지만 이번에 요구된 색상 검증을 충족하지 않으므로 신규 B 완료 건수로 세지 않는다.

## 5. 기존 기능·등록 경계

- 추천: smartphone-catalog.js matchesHardConditions는 모델/변형 verified와 유효 판매가를 요구한다. A+B 검증 제품이라도 C2가 없으면 예산 기반 추천 후보는 계속 제외한다. ‘카탈로그 only_recommendable 목록’의 검증/출시기간 필터 통과와 실제 가격 포함 추천 적격성을 혼동하지 않는다.
- 보유 기기: 가격이 없어도 확인된 모델/변형의 검색·선택·등록은 가능하다. 출시3년 제한을 새로 적용하지 않는다. 기존 member.js의 검색/등록 및 카탈로그 일부 조회에는 미검증행 차단이 없어, pending/verified=false를 운영DB staging으로 쓰지 않는다. 신규 운영 적재는 A+B 완료 및 별도 검수/운영 승인을 받은 허용목록만 대상으로 한다. 미승인 데이터가 노출되지 않는다는 보장은 이번 문서 변경만으로 생기지 않는다.
- 업그레이드: verified와 정확한 국내 출시일/ID를 유지하면 기존3년 판정을 유지할 수 있다. 출고가/현재가 누락이 기기 연령 판정을 막지 않는다. 이번 신규 후보의 2025/2026 출시일은 검토 기준일에3년 미만이며 구매 권유로 해석하지 않는다. 실제 교체 추천은 C2가 별도로 필요하다.
- 기존16/29의 ID/FK/verified/색상/출시일 보존. 기존행과 모델번호가 일치하면 기존ID를 사용하고 조사null로 덮어쓰지 않는다. 한 변형 검증을 다른 형제 변형 verified=true로 확장하지 않는다.
- RAM 생성키/unknown→known 중복 대응 설계는 유지한다. 현재 2개 구성에는 RAM 유일키 변경이 선행조건은 아니지만, 이후 같은 모델·용량·색상에 다른RAM이 확인되면 기존 키로는 표현 불가하므로 확장 검증이 필요하다.
- 운영 공개·자료 이용 검토 및 사용자의 실제 적재 승인은 별도 미완료다. 이를 이유로 사실 검증된 구성을 다시0개로 집계하지 않는다. 기존 정책을 완화하거나 권리 확보로 기록하지 않는다.
