# 기기로움 팀 회의 요구사항

기준일: 2026-11-13 (Asia/Seoul). 상태: **사용자가 확정한 요구사항**, 구현 완료 선언 아님.

## 문서 책임과 적용

이 문서는 이번 팀 회의의 제품 요구사항 기준이다. 기술 목표는 [통합 추천 설계](INTEGRATED_RECOMMENDATION_DESIGN.md), 실행 순서는 [백엔드 로드맵](BACKEND_ROADMAP.md)을 따른다. 기존 [프로젝트 개요](PROJECT_OVERVIEW.md), [아키텍처](ARCHITECTURE.md), [결정 기록](DECISIONS.md)은 배경·기존 계약이며, 이번에 달라진 목표는 아래 전환 사항으로 명시한다. [공통 개발 규칙](DEVELOPMENT_RULES.md)과 [AI 작업 규칙](AI_WORKFLOW.md)은 변경하지 않는다. 실제 구현 기록은 [현재 상태](CURRENT_STATUS.md), [인계 문서](AI_HANDOFF.md), [개발 로그](DEVELOPMENT_LOG.md), 검증 기준은 [테스트 계획](TEST_PLAN.md)을 참조한다. 오래된 상태 문장은 최신 구현 증거로 사용하지 않는다.

## 확정: 서비스 정체성과 제품군

기기로움은 **AI 기반 개인 성향 맞춤형 IT 기기 추천 플랫폼**이다. 사용자의 성향·구매 목적·예산·선호도·기존 사용 기기를 고려한 적합한 선택이 핵심이다. 신제품·가격 변화·추가 투자·이벤트·뉴스는 이를 보완하며 메인 서비스를 대체하지 않는다.

지원 목표는 스마트폰, 태블릿, 스마트워치, 스피커, 무선이어폰, 노트북의 6개 제품군이다. 스마트폰부터 구현·검증한다. 나머지 제품군의 DB·평가 규칙이 준비됐다고 가정하지 않는다. PC-FIT 조립 PC 및 개별 부품 추천은 별도 향후 TODO다.

## 확정: 기능 구분

| 구분 | 요구사항 |
|---|---|
| 핵심 | 프로필·보유 기기 기반 개인화 추천, 제품 스펙 비교, 유지·교체 판단 |
| 보조 | 조건부 추가 투자 안내, 공식 출시 일정 참고, 실제 관측된 이전 세대 가격 변화, 현재 기기 유지 |
| 부가 | 이벤트·할인 혜택 API, IT 뉴스 API |

핵심 기술은 **AI 요구 해석 + 전문 성능 자료 분석 + 로컬 가중치 평가 + AI 근거 설명**이다. 로컬 엔진이 최종 순위를 결정한다. AI는 DB 밖 제품을 추천하거나 검증되지 않은 수치를 생성하지 않는다. 내부 점수·가중치는 일반 사용자에게 노출하지 않으며 장단점과 이유를 자연어로 설명한다.

현재 명시한 조건이 과거 사용 기기에서 추정한 성향보다 우선한다. 필수 조건은 필터이며 선호 조건은 평가 요소다. 이번 예산·조건을 영구 프로필에 자동 병합하지 않는다. 최고 성능·최저가 대신 사용 목적별 개인화 가성비를 평가한다.

## 확정: 일반 추천과 업그레이드

- 일반 추천: 새로운 제품 탐색. 구매 목적·예산·선호·가성비·프로필을 사용하며 보유 기기는 선택 입력이다.
- 업그레이드 분석: 현재 기기 유지와 교체의 필요성 판단. 현재 기기, 만족·불편, 실제 개선 근거, 교체 비용을 사용한다. KEEP / REPLACE / DEFER / CLARIFY 구조를 유지하는 방향으로 설계한다. 구매하지 않는 결과도 정상이다.
- 공통 모듈은 요구 해석·후보 조회·성능 근거·가격 검증·설명 생성이다. 제품 순위와 교체 필요성 판단은 별도 정책이다. 메뉴만 분리하는 구현은 목표를 충족하지 않는다.

## 확정: 비교·보조·부가 기능

기존 비교 UI/UX를 보존한다. 항목별 우세·동률·단순 차이·자료 부족·비교 불가·개인 선호에 따른 장단점을 구분하고 AI 설명을 추가한다. 수치가 크다는 이유만으로 우세로 판정하지 않는다. 객관적 수치 비교는 로컬에서 수행한다. 기존 일반 스펙 비교는 AI 없이 이용 가능해야 하며, AI 설명은 추가 기능이다.

추가 투자는 목적에 중요한 검증된 이득이 있을 때만 별도로 안내한다. 기존 예산 필터를 몰래 완화하지 않는다. 공식 신제품 일정과 루머를 구분하며 가격 하락은 관측 사실로만 다룬다. 기다리면 반드시 저렴해진다는 예측은 하지 않는다.

이벤트 API는 이벤트명·제품·혜택·적용 조건·공식 출처·유효기간을, 뉴스 API는 출처·발행일·제품군·원문 링크·요약을 관리하도록 계획한다. 뉴스 카드와 메인 디자인은 향후 프론트엔드 담당 조원 범위다.

## 확정: 데이터와 협업

외부 전문 자료의 출처·측정 항목·버전·환경·확인 시점·검증 상태를 관리한다. 출처 불명 또는 비교 불가능한 측정치는 점수에 사용하지 않는다. Geekbench, 3DMark, Cinebench, Notebookcheck, RTINGS, 제조사 자료는 참고 후보이며 수집·저장·재사용 권한은 미확인이다. 국립전파연구원 자료는 국내 모델 식별 보조이며 판매 구성·전체 사양의 유일한 근거가 아니다.

제품군별 상세 DB는 DB 담당 조원과 협의한다. 원본의 정상 동작을 먼저 확보한 후 원본을 보존하고 팀 통합용 복제본을 만든다. 통합본에는 Mac·Windows 실행 안내, MySQL 마이그레이션·초기 시드, 개인별 로컬 DB, 비밀값 없는 `.env.example`, 공용 API·DB 계약, 공통 AI 개발 규칙, GitHub 협업 환경을 준비한다. 실제 키·비밀번호·사용자 데이터는 복제 대상에서 제외한다.

원본에서는 백엔드와 서비스 기능 검증을 우선하며 신규 디자인 개선은 하지 않는다. 기능 검증에 필요한 프론트 연결은 유지한다. 다나와 Phase 5는 Antigravity 담당이며 이번 문서 작업에서 구현 결과를 검증하지 않았다.

## 현재 구현과 목표의 차이

현재 코드에는 인증·프로필·보유 기기·스마트폰 후보 조회·Gemini 추천·서버 결과 검증·이력·업그레이드 판단이 있다. 현재 실제 AI 모드의 순위는 Gemini가 정하며 Mock 점수 함수는 범용 로컬 평가 엔진이 아니다. 스마트폰은 API 기반 비교, 태블릿·워치는 정적 참고 데이터 기반 비교 코드가 있다. 구현 존재와 최신 실행 성공은 구분한다. 이번 작업은 실행·DB 조회를 하지 않았다.

이번 확정 목표는 로컬 최종 순위, 6개 제품군 설정 기반 평가, 외부 성능 근거 활용, AI 비교 설명 및 구매 보조 기능이다. 이는 아직 구현 완료가 아니다. 상세 전환과 미해결 결정은 통합 설계를 따른다.
