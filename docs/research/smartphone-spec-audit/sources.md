## 2. 출처 신뢰도 등급 체계 및 엄격 적용 기준

1. **제조사 공식 출처 (`official_verified`)**:
   - 삼성전자 뉴스룸 보도자료 (`https://news.samsung.com/kr/`)
   - 삼성전자 공식 제품 스펙/지원 (`https://www.samsung.com/sec/`)
   - Apple Korea 공식 기술사양 문서 (`https://support.apple.com/ko-kr/`)
   - Apple Newsroom Korea (`https://www.apple.com/kr/newsroom/`)
   - 통신사 단독 모델 공식 보도자료 (SKT 뉴스룸, LG U+ 보도자료)
   - **적용 규칙**: 출처 페이지 본문 및 스펙표에 해당 모델번호와 수치가 명시적으로 일치할 때만 부여.

2. **규제기관 및 개발자 공인 2차 출처 (`secondary_verified`)**:
   - **국립전파연구원(NRRA) / KTC 적합성인증 고시**: Apple 전 모델의 배터리 정격 용량(mAh) 적재 근거.
   - **Apple Developer Display API (`CADisplayLink`, `UIScreen`)**: 일반 iPhone의 고정 60Hz 주사율 근거.
   - **Apple Developer Runtime Profile**: Apple 기기별 실제 탑재 RAM(GB) 근거.
   - **적용 규칙**: 제조사 소비자 마케팅 스펙에서 비공개하는 항목을 공인 기관 인증으로 입증한 경우 엄격 분리.

3. **검토 보류 (`pending_review`)**:
   - 공식 출처 페이지에서 해당 항목이 명시되지 않고 2차 규제기관 고시도 추가 확인이 필요한 사양. 추측에 의한 값 채우기 금지.
